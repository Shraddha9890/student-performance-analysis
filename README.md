# 🎓 Student Performance Analysis

## 📌 Project Overview
This project analyzes student performance based on various factors such as gender, parental education, lunch type, and test preparation course.

## 📊 Dataset
- Source: Students Performance Dataset
- Format: Excel (.xls)

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

## 🔍 Key Analysis
- Gender-based performance comparison
- Impact of test preparation courses
- Relationship between parental education and scores
- Score distribution visualization

## 📈 Results
- Students who completed test preparation performed better
- Parental education level has a noticeable impact
- Female students performed slightly better in reading and writing
